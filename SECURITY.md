# Security

Report vulnerabilities privately through
[GitHub security advisories](https://github.com/Alien6-Studio/hankoshell-golang-adk/security/advisories/new).
Do not include tokens, private keys, customer data or live endpoints in public
issues. Include the affected package version and a synthetic reproduction.

The project is preparing its first public release. No stable support window is
claimed before that release. Authentication fixes must preserve the same token
acceptance contract in Go and TypeScript.
