# 0.7.1 — Aligned application integration

Milestone: https://github.com/Alien6-Studio/hankoshell-golang-adk/milestone/2

## Product outcome

Go and TypeScript applications use the same qualified integration version: **0.7.1**. Keep application sessions across replicas and restarts, end the shared session on sign-out, and distinguish invalid authentication from an organization or application-role refusal.

This delivery consolidates the reviewed identity and delivery dependencies. Applications retain their explicit business-account binding, application permissions and supported Go toolchain. Existing public releases retain their original names; Go joins the common version line at 0.7.1.

## Qualification and delivery

Qualification includes race tests, static analysis, the official vulnerability check, portable access-contract fixtures shared with TypeScript, and the PostgreSQL reference covering independent runtimes, concurrent renewal, restart, logout fencing and uncertain outcomes without replay.

Required checks and a signed source/output attestation gate the protected public release. Verify the official Go module and TypeScript package at the same version before updating consumers.
