# 0.2.0 — Application integration

Milestone: https://github.com/Alien6-Studio/hankoshell-golang-adk/milestone/1

## Intended experience

Applications keep sessions across replicas and restarts, renew access safely, and end sessions reliably on sign-out. An authorization refusal identifies its category without exposing a token or provider response.

The public module supplies shared encrypted session persistence, renewal ownership, application-scoped access resolution and HTTP integration. Applications retain ownership of account binding and business permissions.

## Acceptance before publication

- Concurrent independent runtimes consume a refresh token at most once.
- Restart preserves valid sessions; logout fences an in-flight renewal.
- An uncertain token exchange cannot be replayed automatically.
- Organization and application isolation remain strict; diagnostics contain only allowlisted categories.
- The runnable reference and normal module/release checks pass before consumer rollout.

## Delivery status

The candidate implements shared sessions, HTTP authentication, typed application-access denials and approved organization selection. Local race tests, static checks, the official vulnerability scan and the PostgreSQL reference pass. Publication and installed-consumer rollout remain pending.
